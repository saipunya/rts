# คู่มือผู้พัฒนา: ออกรหัสใช้งาน RTS Demo

ผู้พัฒนา: สุเมธ ชูรัตน์ · โทร 080-8281906 · LINE saipunya

## หลักการ

ลูกค้าทดลองได้ 60 วันเต็ม นับจากเวลาที่เตรียมระบบสำเร็จครั้งแรก เมื่อหมดอายุ หน้าใช้งานและจุดบันทึกข้อมูลจะให้ไปหน้าขอรหัส โดยไม่ลบข้อมูล ลูกค้าส่งรหัส `RTSREQ1.…` มาให้ผู้พัฒนา และนำรหัส `RTS1.…` ที่ได้รับกลับไปวางในหน้าสิทธิ์ใช้งาน

รหัสผูกกับเครื่องและรหัสชุดติดตั้ง ไม่ใช่รหัสกลางสำหรับทุกสหกรณ์ ตรวจด้วย public key ในโปรแกรม ไม่ต้องเชื่อมต่ออินเทอร์เน็ต ผู้พัฒนาเลือกออกแบบกำหนดวันหรือไม่จำกัดเวลาได้

## เก็บกุญแจสำหรับออกรหัส

สร้างกุญแจจริงให้แล้วที่ `private/signing-private.pem` ในโฟลเดอร์นี้ ไฟล์นี้ถูก ignore จาก Git และไม่รวมในตัวติดตั้ง ส่วน public key อยู่ที่ `demo/license_public.pem`

**สำรองโฟลเดอร์ private ไว้ในที่ปลอดภัยของผู้พัฒนา** อย่าส่งโฟลเดอร์ developer-tools หรือ private ให้ลูกค้า อย่าสร้างกุญแจใหม่ทับชุดนี้ เพราะตัวติดตั้งที่แจกไปตรวจรหัสกับ public key เดิม หากย้ายเครื่องพัฒนา ต้องย้าย private key จากสำรองกลับมาด้วย

โปรแกรมออกรหัสต้องมี PHP พร้อม OpenSSL ในเครื่องพัฒนา บน Mac เครื่องนี้ใช้คำสั่ง php ได้แล้ว บน Windows สามารถใช้ PHP ที่ติดตั้งกับ RTS Demo ที่ `C:\Program Files\RTS Demo\runtime\php\php.exe` โดยเปิด extension openssl ใน php.ini ที่ใช้กับเครื่องมือ หรือเรียกด้วย `-d extension_dir=... -d extension=openssl`

## ตัวอย่างออกรหัส

รันจากโฟลเดอร์ repository เปลี่ยน `RTSREQ1.…` เป็นข้อความทั้งหมดที่ลูกค้าส่งมา:

```sh
php demo/developer-tools/license.php issue --request 'RTSREQ1.…' --days 365 --output activation.txt
```

รหัสแบบกำหนดวันเริ่มนับจากเวลาที่ออกรหัส ไม่ได้เริ่มจากวันที่ลูกค้านำไปกรอก โปรแกรมจะแจ้งวันหมดอายุเวลาไทย ตรวจเงื่อนไขที่ตกลงกับลูกค้าก่อนส่ง

หากต้องการให้ไม่จำกัดเวลา:

```sh
php demo/developer-tools/license.php issue --request 'RTSREQ1.…' --permanent --output activation.txt
```

ส่งเฉพาะเนื้อหาไฟล์ activation.txt ให้ลูกค้า รหัสใส่ก่อนหมดช่วงทดลองได้ และไม่ลดอายุทดลองเดิม หากเป็นการต่อสิทธิ์ที่มีอยู่ รหัสใหม่ต้องไม่หมดอายุก่อนรหัสปัจจุบัน

เครื่องมือไม่ออกแบบการชำระเงินอัตโนมัติ ผู้พัฒนาเป็นผู้อนุมัติการออกรหัสเอง ไม่มีส่วนส่งข้อความให้ลูกค้าอัตโนมัติ

## สิ่งที่เก็บในเครื่องลูกค้า

- ฐานข้อมูลและไฟล์แอป: `%LOCALAPPDATA%\RTSDemo`
- ประวัติสิทธิ์และรหัสที่เปิดใช้: `%LOCALAPPDATA%\RTSDemoLicense`
- สำเนาสถานะสิทธิ์ที่ป้องกันด้วย Windows DPAPI: `HKCU\Software\RTSDemo\Licensing`

ประวัติสิทธิ์แยกจาก SQL backup การล้างเดโม กู้คืนฐานข้อมูล และถอนแล้วติดตั้งใหม่ตามปกติไม่เริ่ม 60 วันใหม่ หากไฟล์ประวัติหาย ตัวเปิดระบบจะกู้จากสำเนา Windows เดิมโดยรักษาวันเริ่มต้นไว้

ตรวจเวลาเครื่องย้อนหลังเทียบกับเวลาสูงสุดที่เคยใช้ โดยยอมคลาดเคลื่อนได้ 5 นาที หากพบให้แก้วันเวลา Windows และเปิดใหม่ หากเคยตั้งเวลาไปไกลในอนาคตจนกลับมาใช้ไม่ได้ ให้ผู้พัฒนาตรวจประวัติและช่วยกู้สิทธิ์ ไม่ควรลบประวัติเพื่อเริ่มทดลองใหม่

## ขอบเขตการป้องกัน

เป็นการควบคุมสิทธิ์แบบออฟไลน์สำหรับสำเนานี้ ผู้ที่แก้ PHP และไฟล์ระบบได้สามารถดัดแปลงให้ข้ามการตรวจได้ และการล้างทั้งประวัติไฟล์กับ Windows registry หรือสร้างโปรไฟล์ Windows ใหม่อาจเริ่มเป็นชุดติดตั้งใหม่ จึงไม่ใช่ระบบป้องกันการคัดลอกที่แก้ไม่ได้ หากต้องควบคุมระดับต่อเครื่องรวมทุกบัญชีหรือเพิกถอนสิทธิ์จากส่วนกลาง ต้องเพิ่มบริการลงทะเบียนออนไลน์/บริการ Windows ที่คุมสิทธิ์ต่างหาก

ข้อมูลติดต่อที่แสดงในหน้าโปรแกรมแก้ได้ที่ `demo/license_settings.php` แล้วสร้างชุดติดตั้งใหม่ การเปลี่ยนข้อมูลติดต่อไม่เปลี่ยนกุญแจออกรหัส
