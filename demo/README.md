# RTS Demo — ชุดติดตั้ง Windows เครื่องเดียว

รุ่นทดลอง 0.3.0 (60 วัน) ใช้ระบบต้นแบบ commit `d5545bd` คงหน้าตา เมนู ขั้นตอนงาน และสูตรคำนวณ แยกไฟล์จากระบบหลัก เปลี่ยนข้อมูลแสดงผลของสหกรณ์เป็นข้อมูลตัวอย่าง และใช้ฐานข้อมูลแยกพร้อมสมาชิกสมมติ 5 คน ไม่มีบัญชีหรือธุรกรรมของสหกรณ์เดิม

## ไฟล์สำหรับผู้ทดลอง

- `dist/RTS-Demo-Setup-x64.exe` — ตัวติดตั้งรวม PHP 8.3, MariaDB 11.4, Microsoft Visual C++ Runtime, ไลบรารี และทรัพยากรหน้าเว็บในเครื่อง ไม่ต้องเตรียม XAMPP
- `manual/คู่มือใช้งาน.html` — คู่มือภาษาไทย เปิดในเบราว์เซอร์และพิมพ์หรือบันทึกเป็น PDF ได้ รวมอยู่ในตัวติดตั้งและโฟลเดอร์ dist ด้วย
- `dist/SHA256SUMS.txt` — checksum ของไฟล์ติดตั้ง

ติดตั้งด้วย Setup.exe บน Windows 10/11 x64 จากนั้นเปิดไอคอน RTS Demo บน Desktop แล้วสร้างบัญชีผู้ดูแลใหม่ รหัสผ่านไม่มีค่าเริ่มต้น เมื่อระบบพร้อมเบราว์เซอร์จะเปิด `http://127.0.0.1:8088/login.php` ให้เอง

เมนู Start → RTS Demo มี Start, Stop, Backup, Restore และคู่มือ ใช้ Stop เมื่อเลิกใช้งาน การปิดเบราว์เซอร์อย่างเดียวไม่หยุดฐานข้อมูล

## ข้อมูลและความเป็นอิสระจากระบบหลัก

เก็บข้อมูลแยกตามบัญชี Windows ที่ `%LOCALAPPDATA%\RTSDemo` ฐานข้อมูลใช้พอร์ต 33188 และเว็บใช้พอร์ต 8088 ทั้งสองผูกกับ 127.0.0.1 ไม่เปิด LAN การถอนโปรแกรมเก็บฐานข้อมูลและสำรองไว้ การเปิดด้วยบัญชี Windows อื่นจะเป็นชุดข้อมูลอื่น

การเชื่อมต่อในชุดติดตั้งอ่าน db_config.php จากตำแหน่งข้อมูลดังกล่าวผ่าน RTS_DEMO_DATA ไม่อ่าน config ของระบบหลัก ผู้พัฒนายังใช้ db_config.php ภายใน demo สำหรับการทดสอบแยกได้เมื่อไม่ได้กำหนด environment นี้ ตัวติดตั้ง CLI รับเฉพาะฐานข้อมูลชื่อ rts_demo ในเครื่อง และปฏิเสธฐานข้อมูลที่มีตารางอยู่แล้ว

## ไฟล์สำหรับพัฒนา

- `windows/Launcher.ps1` — เตรียมข้อมูลครั้งแรก เริ่ม/หยุด process ของชุดนี้ ตรวจความพร้อม สำรองและกู้คืน
- `windows/installer.nsi` — ตัวติดตั้ง NSIS พร้อมไอคอนและการถอนโปรแกรม
- `windows/build.py` — ประกอบและคอมไพล์ชุดติดตั้ง
- `windows/fetch_runtime.py`, `runtime-lock.json` — ดาวน์โหลดจากแหล่งทางการและตรวจ SHA256
- `windows/prepare_offline.py` — รวม CSS, JS, icon fonts และใช้ฟอนต์ในเครื่อง
- `windows/test_demo.py` — ทดสอบบนฐานข้อมูลชั่วคราว ไม่เชื่อมต่อฐานข้อมูลจริง
- `setup/schema.sql`, `setup/install.php` — ติดตั้ง schema แล้วเรียก helpers ของต้นแบบ สร้างผู้ดูแลใหม่และสมาชิก D001–D005 รหัสบุคคล 1234

ดูคำสั่งสร้างและทดสอบใน `windows/README-build.md` ไฟล์ดาวน์โหลด stage และ dist ไม่ถูกเพิ่มเข้า Git อัตโนมัติ เพราะมีขนาดใหญ่

## สถานะการตรวจ

ดูผลจริงใน `windows/VALIDATION.md` การคอมไพล์สำเร็จและการทดสอบบน macOS ไม่ยืนยันผลบน Windows ต้องตรวจรับบน Windows จริงตามคู่มือก่อนส่งให้สหกรณ์หรือระบุว่าพร้อมจำหน่าย

## ทดลอง 60 วันและขอรหัสใช้งานต่อ

เริ่มนับ 60 วันเมื่อเตรียมระบบสำเร็จครั้งแรก แสดงวันคงเหลือและวันหมดอายุบนหน้าเว็บ เมื่อครบกำหนดจะหยุดหน้าใช้งานและการบันทึกข้อมูล โดยข้อมูลเดิมยังอยู่ และยังสำรองผ่านเมนู Windows ได้

ติดต่อผู้พัฒนา สุเมธ ชูรัตน์ โทร 080-8281906 · LINE saipunya แล้วส่งรหัสขอใช้งานจากหน้า activation.php ผู้พัฒนาออกได้ทั้งรหัสกำหนดวันและไม่จำกัดเวลา รหัสมีลายเซ็นและผูกกับชุดติดตั้งในเครื่องนั้น ไม่ต้องต่ออินเทอร์เน็ตขณะกรอก

เก็บประวัติสิทธิ์นอกฐานข้อมูลที่ `%LOCALAPPDATA%\RTSDemoLicense` และ Windows checkpoint ที่ป้องกันด้วย DPAPI การกู้คืน SQL ล้างเดโม และถอนติดตั้งตามปกติไม่เริ่มเวลาใหม่

ดูวิธีออกรหัส ข้อจำกัดแบบออฟไลน์ และวิธีสำรอง signing key ใน `developer-tools/README.md` เครื่องมือและ private key ไม่อยู่ในตัวติดตั้ง ห้ามส่งโฟลเดอร์ developer-tools/private ให้ลูกค้า
