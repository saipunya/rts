# ผลตรวจ RTS Demo 0.1.0

วันที่ตรวจ: 7 พฤศจิกายน 2026

## ตรวจแล้วในเครื่องพัฒนา macOS ARM64

- PHP syntax ผ่าน 71 ไฟล์
- ตัวติดตั้ง CLI สร้างฐานข้อมูลใหม่ใน MariaDB instance ชั่วคราวที่แยกจากระบบจริงได้ สร้างสมาชิกสมมติ 5 คนและผู้ดูแลใหม่ 1 บัญชี
- ปฏิเสธการติดตั้งซ้ำเมื่อฐานข้อมูลมีตารางอยู่แล้ว
- อ่าน config จาก RTS_DEMO_DATA และเข้าสู่ระบบด้วยบัญชีใหม่ได้
- เปิดหน้าสมาชิก วางยาง ราคา จัดการวางยาง ชั่ง ยอดหัก อนุมัติ และล้างข้อมูลเดโมได้
- ชุดทดสอบขั้นตอนงานเดิม `tests/weighing_integration.php` ผ่าน 196 checks เมื่อรันกับสำเนา demo และฐานข้อมูลชั่วคราว
- สำรอง SQL แล้วนำเข้าฐานข้อมูลทดสอบอีกชุดได้ ตรวจจำนวนสมาชิกและบัญชีตรงกัน ไม่มีรายการรับซื้อเดิม
- หน้าเว็บไม่มี URL สำหรับโหลด CSS/JS/Google Fonts จากภายนอก และไฟล์ assets ที่อ้างถึงมีอยู่จริง
- Router ตอบ health identity ได้ และกั้น config, SQL, installer, Windows scripts และ vendor จากการเรียกผ่านเว็บ
- PowerShell scripts ผ่าน parser ของ PowerShell 7 และทดสอบ helper สำหรับ argument quoting และ UTF-8 stdin แล้ว ผลนี้ไม่ใช่การรัน Windows Forms หรือ process lifecycle บน Windows PowerShell 5.1
- Runtime ดาวน์โหลดจากแหล่งทางการ ตรวจ SHA256 ตาม runtime-lock.json รวม upstream source archive ของ MariaDB ไว้ในชุดติดตั้ง

ไฟล์ config ที่ใช้ทดสอบอยู่ใน temporary directory เท่านั้น ไม่ได้อ่าน config หรือเปลี่ยนฐานข้อมูลของระบบจริง ฐานข้อมูลชั่วคราวถูกปิดและลบหลังตรวจเสร็จ

## ยังต้องตรวจบน Windows จริง

- เรียกตัวติดตั้ง NSIS, UAC, Microsoft runtime signature/installation, shortcuts และการถอนติดตั้ง
- Windows PowerShell 5.1, หน้าต่างสร้างบัญชี และการเริ่ม/หยุด PHP/MariaDB จาก runtime Windows ที่รวมไว้
- ชื่อบัญชี Windows ภาษาไทยหรือมีช่องว่าง การเปิดซ้ำ พอร์ตชน และการเริ่มหลังรีสตาร์ต
- ทำงานออฟไลน์ครบวงจร ตรวจฟอนต์และกราฟด้วยสายตา รวม PDF/Excel และการพิมพ์จริง
- Backup/Restore ผ่านเมนู Windows และตรวจผลธุรกรรมทั้งก่อนและหลังกู้คืน
- ยืนยันว่าอัปเดตหรือถอนโปรแกรมแล้วข้อมูลผู้ใช้ยังอยู่

ต้องบันทึกผลบน Windows เพิ่มก่อนระบุว่าพร้อมแจกใช้งานจริงหรือพร้อมจำหน่าย การสร้าง PE installer สำเร็จไม่แทนผลทดสอบติดตั้งบน Windows

## ผลสร้างและตรวจแพ็กเกจ

- NSIS คอมไพล์ไฟล์ `demo/dist/RTS-Demo-Setup-x64.exe` สำเร็จโดยไม่มี compiler warnings ในการ build สุดท้าย
- ขนาดไฟล์ประมาณ 340 MiB รวม runtime, แอป, คู่มือ, ใบอนุญาต และซอร์ส MariaDB
- `verify_package.py` ตรวจผ่าน: PE installer, runtime binaries แบบ x64, checksum, ไม่มี config จริงใน payload, ไฟล์หน้าเว็บในเครื่อง, ฟอนต์คู่มือ และ PowerShell payload ตรงกับ source ล่าสุด
- NSIS bootstrap เป็น PE32 ซึ่งเป็นตัวติดตั้งมาตรฐานของ NSIS ส่วน PHP/MariaDB payload เป็น Windows x64 และตัวติดตั้งตรวจ Windows x64 ก่อนดำเนินการ
- SHA256: `a213b678d8051960563e2f5a5c286cc59aa8f52fc382977b589aad49b1f28d9f`

## รุ่น 0.2.0 — ทดลอง 60 วันและรหัสใช้งาน

เพิ่มระยะทดลอง 60 วันนับจากเตรียมระบบสำเร็จ เก็บประวัตินอกฐานข้อมูล เพิ่มหน้าขอรหัสและแสดงวันคงเหลือ ใช้ RSA/SHA256 ตรวจรหัสที่ผูกกับรหัสชุดติดตั้งและเครื่อง ผู้พัฒนาออกได้ทั้งกำหนดวันและไม่จำกัดเวลา

ผลตรวจใน macOS:

- PHP syntax ผ่าน 75 ไฟล์
- ชุดทดสอบสิทธิ์ `demo/tests/license_test.php` ผ่าน 35 ข้อ โดยใช้กุญแจชั่วคราว ไม่ใช้ private key จริงของผู้พัฒนา
- ตรวจขอบเขต 60 วันพอดี วันหมดอายุรหัส รหัสผิดเครื่อง/ชุดติดตั้ง รหัสแก้ไข การย้อนหลังเวลา การไม่เริ่มวันใหม่ และการกู้ checkpoint ที่รักษาวันเดิม
- ทดสอบ HTTP: ผู้ใช้ที่มี session อยู่แล้วถูกบล็อกทั้ง GET และ POST เมื่อหมดอายุ รวมหน้าสมาชิก ชั่ง บันทึก และส่งออก
- POST ล้างเดโมขณะหมดอายุไม่เปลี่ยนข้อมูลสมาชิก ตรวจว่ายังคงอยู่ 5 รายการ
- หน้า activation เปิดได้ขณะหมดอายุ แสดงชื่อ สุเมธ ชูรัตน์ โทร 080-8281906 และ LINE saipunya
- CSRF ผิดถูกปฏิเสธ รหัสผิดไม่ปลดล็อก รหัสลงลายเซ็นที่ถูกต้องปลดล็อกผ่านเว็บและกลับไปดูสมาชิกเดิมได้
- ชุดทดสอบขั้นตอนงานต้นแบบยังผ่าน 196 ข้อ และ SQL backup round-trip ผ่าน
- PowerShell scripts ผ่าน parser หลังเพิ่ม Windows checkpoint/DPAPI
- private/signing-private.pem ถูก ignore จาก Git และ build ไม่รวม developer-tools หรือ private key ใน payload รวมเฉพาะ public key

ยังไม่ได้รันตัวติดตั้งรุ่นนี้บน Windows จริง โดยเฉพาะ Windows MachineGuid, DPAPI/registry, การรักษาสิทธิ์หลังถอนแล้วติดตั้งใหม่ และหน้าต่าง native launcher ต้องตรวจตามคู่มือก่อนแจกจริง ยังไม่ได้ตรวจหน้าตาหน้า activation ด้วยภาพในเบราว์เซอร์ เพราะ session นี้ไม่มี browser surface ให้ใช้งาน

การควบคุมแบบออฟไลน์ไม่ป้องกันผู้ที่แก้ source PHP หรือแก้ทั้งไฟล์ประวัติกับ Windows registry ได้ทั้งหมด ดูข้อจำกัดใน developer-tools/README.md

ตัวติดตั้ง 0.2.0 คอมไพล์สำเร็จและ verify_package.py ผ่านแล้ว ขนาดประมาณ 340 MiB รวม public key ที่ตรงกับกุญแจผู้พัฒนา และยืนยันว่าไม่มี private key หรือ developer-tools ใน payload
