RTS DEMO · WINDOWS x64 · รุ่นทดลอง 0.3.0

คู่มือติดตั้งและทดลองใช้
ระบบรวบรวมยางสำหรับสหกรณ์

ใช้ต้นแบบระบบรวบรวมยางเดิม ทั้งหน้าตา ขั้นตอนงาน และสูตรคำนวณ พร้อมสมาชิกสมมติสำหรับทดลองบนคอมพิวเตอร์เครื่องเดียว ชุดติดตั้งรวม PHP เว็บเซิร์ฟเวอร์ ฐานข้อมูล และไฟล์หน้าเว็บที่ใช้ในเครื่องไว้แล้ว ไม่ต้องติดตั้ง XAMPP หรือ Composer เพิ่ม

สถานะรุ่นนี้: เป็นชุดสำหรับทดสอบก่อนนำไปแจก ต้องตรวจรับบน Windows จริงให้ครบรายการท้ายคู่มือก่อนใช้เป็นรุ่นพร้อมจำหน่าย ไม่มีข้อมูลสมาชิกหรือรายการธุรกรรมของสหกรณ์ต้นแบบอยู่ในชุดนี้

เตรียมเครื่องติดตั้งเปิดครั้งแรกทดลองทำงาน60 days / Activationสำรองและกู้คืนแก้ปัญหา

1. เตรียมเครื่อง

  • Windows 10 หรือ Windows 11 แบบ 64 บิต (Intel/AMD x64) พร้อมเบราว์เซอร์ เช่น Microsoft Edge หรือ Chrome
  • แนะนำ RAM 4 GB ขึ้นไป และพื้นที่ว่างอย่างน้อย 3 GB สำหรับโปรแกรม ข้อมูล และการติดตั้ง พื้นที่สำรองจะเพิ่มตามการใช้งาน
  • ต้องใช้สิทธิ์ผู้ดูแล Windows เฉพาะตอนติดตั้งส่วนประกอบ เปิดใช้งานประจำวันด้วยบัญชี Windows ปกติ
  • ไฟล์ติดตั้งรวมส่วนประกอบไว้แล้ว จึงไม่ต้องใช้อินเทอร์เน็ตระหว่างติดตั้งหรือใช้ขั้นตอนหลัก แต่การอัปเดต Windows และใบรับรองอาจจำเป็นหากเครื่องเก่าตรวจลายเซ็น Microsoft ไม่ผ่าน

2. ติดตั้งโปรแกรม

  1. คัดลอกไฟล์ RTS-Demo-Setup-x64.exe ลงเครื่อง Windows แล้วดับเบิลคลิก
  2. เมื่อ Windows ขอสิทธิ์ติดตั้ง ให้ตรวจว่าเป็นไฟล์ที่ได้รับจากผู้พัฒนา แล้วกดอนุญาต ชุดทดลองนี้ยังไม่ได้ลงลายเซ็นผู้พัฒนา หากระบบความปลอดภัยขององค์กรบล็อก ให้ติดต่อผู้ดูแลหรือผู้พัฒนา ไม่ต้องปิดระบบป้องกันไวรัส
  3. ทำตามตัวติดตั้ง ใช้ตำแหน่งเริ่มต้น C:\Program Files\RTS Demo ได้ ตัวติดตั้งจะเตรียม Microsoft Visual C++ Runtime ที่ PHP ต้องใช้ด้วย
  4. เมื่อติดตั้งเสร็จ กด Finish หากมีข้อความให้รีสตาร์ต ให้รีสตาร์ตเครื่องก่อนเปิดระบบ
  5. เปิดไอคอน RTS Demo บน Desktop ด้วยบัญชี Windows ที่จะใช้ทดลอง ไม่ต้องเลือก Run as administrator

3. เปิดครั้งแรกและสร้างบัญชี

  1. ระบบแสดงหน้าต่างสร้างผู้ดูแล กำหนดชื่อผู้ใช้เป็นตัวอักษรอังกฤษ ตัวเลข ขีดกลาง หรือขีดล่าง และตั้งรหัสผ่านอย่างน้อย 10 ตัวอักษร พิมพ์ยืนยันให้ตรงกัน
  2. จดชื่อผู้ใช้และเก็บรหัสผ่านไว้ในที่เหมาะสม ไม่มีรหัสผู้ดูแลสำเร็จรูปหรือบัญชีเดิมของสหกรณ์ต้นแบบ
  3. รอระบบเตรียมฐานข้อมูลครั้งแรก จากนั้นเบราว์เซอร์จะเปิดหน้าเข้าสู่ระบบโดยอัตโนมัติ
  4. เข้าสู่ระบบด้วยบัญชีที่เพิ่งสร้าง ตรวจว่าพบชื่อ สหกรณ์ตัวอย่าง (ระบบทดลอง) และสมาชิกสมมติ 5 คน

หน้าระบบ: http://127.0.0.1:8088/login.php ข้อมูลอยู่ในคอมพิวเตอร์เครื่องนี้ ระบบรุ่นนี้ไม่ได้เปิดให้เครื่องอื่นในเครือข่ายเชื่อมต่อ

บัญชี Windows แต่ละคนมีข้อมูลทดลองแยกกัน ควรเปิดด้วยบัญชี Windows เดิมทุกครั้ง หากเปลี่ยนบัญชี Windows จะเป็นการเริ่มชุดข้อมูลใหม่ ไม่ใช่ข้อมูลหาย

4. เปิดและปิดในแต่ละวัน

ต้องการวิธีทำ
เปิดใช้งานดับเบิลคลิก RTS Demo บน Desktop รอเบราว์เซอร์เปิด กดซ้ำจะใช้ระบบเดิมที่กำลังทำงานอยู่
ปิดระบบบันทึกงานและออกจากระบบ แล้วเปิดเมนู Start → RTS Demo → Stop RTS Demo รอข้อความปิดสำเร็จ
ปิดแค่เบราว์เซอร์เว็บเซิร์ฟเวอร์และฐานข้อมูลยังทำงานอยู่ หากเลิกใช้งานควรเลือก Stop RTS Demo ด้วย
เปิดหลังรีสตาร์ตเปิด RTS Demo อีกครั้ง ข้อมูลที่บันทึกแล้วจะยังอยู่ ระบบไม่ได้ตั้งบริการให้เริ่มพร้อม Windows

5. ทดลองกระบวนการรวบรวมยาง

ข้อมูลตั้งต้นมีสมาชิก D001–D005 ชื่อ “สมาชิกสมมติ 1” ถึง “สมาชิกสมมติ 5” กลุ่ม 1 และรหัสบุคคล 1234 สำหรับทดลองหน้าสมาชิก รหัสนี้เป็นข้อมูลสมมติ ไม่ใช่รหัสบัญชีผู้ดูแล

  1. ตรวจข้อมูลสมาชิก: เปิดหน้าสมาชิก ดูสมาชิกตั้งต้น หรือเพิ่มสมาชิกสมมติจากแบบฟอร์มเดิม
  2. บันทึกวางยาง: เลือกสมาชิก ลาน และจำนวนกระสอบ แล้วบันทึกตามขั้นตอนต้นแบบ
  3. กำหนดราคา: บันทึกวันที่ราคาและราคาต่อกิโลกรัมสำหรับรอบที่จะทดลอง วันที่ราคาต้องไม่อยู่ในอนาคต
  4. ตรวจวันวางยาง: ต้นแบบใช้วันวางยางก่อนวันที่ราคา 1–2 วัน หากสร้างรายการวันนี้แล้วต้องการสาธิตทันที ให้ผู้ดูแลแก้วันที่วางยางในหน้าจัดการเป็นเมื่อวานหรือสองวันก่อน แล้วใช้วันที่ราคาวันนี้ ไม่ต้องเปลี่ยนวันที่ Windows
  5. ชั่งน้ำหนัก: เปิดหน้าชั่ง เลือกวันและลาน กรอกน้ำหนักสุทธิเป็นกิโลกรัม เลือกรอบราคา และยืนยัน ระบบเก็บราคาที่ใช้กับรายการตามวิธีเดิม
  6. อนุมัติและยอดหัก: ตรวจคิวอนุมัติและบันทึกยอดหักตามเส้นทางที่หน้าจอแสดง โดยคงสิทธิ์และข้อกำหนดต้นแบบ หากไม่มียอดหัก ให้กรอก 0 ในช่องที่ต้องยืนยัน
  7. ตรวจยอดและเอกสาร: ตรวจน้ำหนัก ราคาที่ใช้ มูลค่า ยอดหัก และยอดสุทธิให้ตรงกัน จากนั้นทดลองพิมพ์ใบเสร็จ รายงาน PDF และ Excel ด้วยข้อมูลชุดเดียวกัน

ค่าทดลองสำหรับตรวจด้วยตนเอง: น้ำหนัก 100 กก. × ราคา 30 บาท/กก. = 3,000 บาท หากรายการมีเฉพาะยอดหัก 100 บาท และไม่มีรายการอื่น ยอดสุทธิควรเป็น 2,900 บาท ให้ตรวจว่าหน้าจอไม่มีค่าใช้จ่ายอื่นก่อนใช้ตัวอย่างนี้เทียบยอด

ระยะทดลอง 60 วันและการขอรหัสใช้งานต่อ

เริ่มนับ 60 วันเต็มเมื่อเตรียมฐานข้อมูลและบัญชีผู้ดูแลครั้งแรกสำเร็จ บนหน้าเว็บมีจำนวนวันที่เหลือและวันหมดอายุ กด สิทธิ์ใช้งาน / ขอรหัสใช้งาน เพื่อตรวจรายละเอียดหรือใส่รหัสได้ทุกเมื่อ

เมื่อครบกำหนด ระบบจะแสดงหน้าขอรหัสและหยุดการเข้าใช้หน้าระบบ รวมถึงการบันทึกข้อมูล ข้อมูลเดิมจะยังอยู่ และยังสำรองข้อมูลได้จาก Start → RTS Demo → Backup RTS Demo การล้างข้อมูล กู้คืนฐานข้อมูล หรือถอนแล้วติดตั้งใหม่ตามปกติไม่เริ่มระยะทดลองใหม่

  1. เปิดหน้าสิทธิ์ใช้งาน แล้วกด คัดลอกรหัสขอใช้งาน ซึ่งขึ้นต้นด้วย RTSREQ1.
  2. ติดต่อ สุเมธ ชูรัตน์ โทร 080-8281906 หรือ LINE ID saipunya แล้วส่งรหัสทั้งหมด รหัสขอใช้งานไม่มีข้อมูลสมาชิก
  3. เมื่อได้รับรหัสที่ขึ้นต้นด้วย RTS1. ให้วางในช่องรหัสใช้งาน แล้วกด เปิดใช้งานต่อ
  4. ตรวจข้อความเปิดใช้สำเร็จและวันหมดอายุใหม่ หรือข้อความไม่จำกัดเวลา ตามสิทธิ์ที่ผู้พัฒนาออกให้ จากนั้นกลับเข้าสู่ระบบด้วยบัญชีเดิมได้ทันที
รหัสใช้ได้กับชุดติดตั้งในเครื่องที่ขอรหัสเท่านั้น ไม่ต้องต่ออินเทอร์เน็ตขณะกรอก หากระบบแจ้งวันที่เครื่องย้อนหลัง ให้ตรวจวันเวลา Windows ให้ถูกต้องก่อนเปิดระบบอีกครั้ง หากยังใช้ไม่ได้ให้ติดต่อผู้พัฒนาและเก็บข้อมูลเดิมไว้

6. สำรองและกู้คืนข้อมูล

สำรองข้อมูล

  1. หยุดบันทึกหรือแก้ไขงานชั่วคราว
  2. เปิด Start → RTS Demo → Backup RTS Demo
  3. รอข้อความสำรองสำเร็จ ระบบเปิดโฟลเดอร์และเลือกไฟล์ rts-demo-วันเวลา.sql ให้
  4. คัดลอกไฟล์ไป USB หรือพื้นที่เก็บข้อมูลอีกแห่ง ข้อมูลสำรองมีสมาชิก บัญชี และธุรกรรมในฐานข้อมูล ควรเก็บเป็นส่วนตัว

ตำแหน่งสำรอง: กด Win+R พิมพ์ %LOCALAPPDATA%\RTSDemo\backups แล้ว Enter การสำรองนี้ครอบคลุมฐานข้อมูล ไม่รวมไฟล์ที่ผู้ใช้แก้เองนอกฐานข้อมูลหรือส่วนประกอบโปรแกรม

กู้คืนข้อมูล

  1. เปิด Start → RTS Demo → Restore RTS Demo
  2. เลือกไฟล์ .sql ที่ได้จาก Backup RTS Demo รุ่นเดียวกัน และยืนยันการแทนที่ข้อมูลปัจจุบัน
  3. ระบบหยุดหน้าเว็บและสำรองข้อมูลเดิมก่อนนำเข้า หากเกิดข้อผิดพลาด ให้เก็บไฟล์สำรองก่อนกู้คืนและติดต่อผู้พัฒนา เพราะการนำเข้า SQL อาจสำเร็จเพียงบางส่วน
  4. เมื่อกู้คืนสำเร็จ เปิด RTS Demo ใหม่ ตรวจสมาชิก รายการ และยอดสำคัญ รหัสเข้าสู่ระบบจะเป็นบัญชีในไฟล์สำรองนั้น
กู้คืนเป็นการแทนที่ข้อมูลตาราง ไม่ใช่การรวมข้อมูลสองชุด ใช้ไฟล์ที่สร้างจาก RTS Demo และไม่แก้ไขไฟล์ SQL เอง

7. ล้างข้อมูลทดลอง อัปเดต และถอนการติดตั้ง

ล้างข้อมูล: ผู้ดูแลใช้เมนูล้างข้อมูลเดโม อ่านรายการที่จะลบ เลือกว่าจะล้างสมาชิกด้วยหรือไม่ แล้วพิมพ์ข้อความยืนยันตามหน้าจอ บัญชีผู้ใช้คงอยู่ ควรสำรองก่อนล้าง เมื่อเลือกเก็บสมาชิกจะทดลองรอบใหม่ต่อได้

ติดตั้งใหม่หรืออัปเดต: สำรองข้อมูลและใช้ Stop RTS Demo ของทุกบัญชี Windows ก่อนเรียกตัวติดตั้ง ใช้รุ่นที่ผู้พัฒนาระบุว่ารองรับข้อมูลเดิม การเปลี่ยนรุ่นฐานข้อมูลหรือ schema ต้องมีขั้นตอนอัปเกรดและทดสอบเพิ่มเติม ไม่ควรใช้ตัวติดตั้งรุ่นอื่นทับเพื่อทดลองเอง

ถอนโปรแกรม: ปิดระบบก่อน แล้วถอน RTS Demo จาก Settings → Apps โปรแกรมจะเก็บข้อมูลและสำรองใน %LOCALAPPDATA%\RTSDemo ไว้ ไม่ลบโดยอัตโนมัติ หากต้องการลบข้อมูลทั้งหมด ให้สำรองและตรวจให้แน่ใจก่อนลบโฟลเดอร์นี้ด้วยตนเอง

8. แก้ปัญหาที่พบบ่อย

อาการสิ่งที่ควรทำ
พอร์ต 8088 หรือ 33188 ถูกใช้ปิด RTS Demo ของบัญชี Windows อื่นหรือโปรแกรมที่ใช้พอร์ตนั้นก่อน ระบบจะไม่ปิดโปรแกรมอื่นให้อัตโนมัติ หากไม่ทราบ ให้ติดต่อผู้พัฒนา
เปิดหน้าเว็บไม่ได้เปิดผ่านไอคอน RTS Demo ก่อน การเปิดลิงก์อย่างเดียวไม่ได้เริ่มฐานข้อมูล หากมีข้อความผิดพลาดให้เก็บข้อความนั้น
เตรียมครั้งแรกไม่สำเร็จระบบเก็บไฟล์ไว้เพื่อกู้คืน ไม่สร้างทับข้อมูลที่มีอยู่ ให้ส่งข้อความผิดพลาดแก่ผู้พัฒนา ห้ามลบโฟลเดอร์ฐานข้อมูลหากมีงานที่ต้องเก็บ
ลืมรหัสผ่านติดต่อผู้ดูแลหรือผู้พัฒนาเพื่อกู้บัญชี ไม่มีรหัสผ่านกลางสำหรับข้ามการเข้าสู่ระบบ
ฟอนต์หรือกราฟไม่แสดงกด Ctrl+F5 หากยังผิดปกติให้เก็บชื่อหน้าและข้อความผิดพลาด ไฟล์หน้าเว็บและฟอนต์ควรโหลดจากเครื่องได้แม้ไม่มีอินเทอร์เน็ต

9. รายการตรวจรับก่อนแจกให้สหกรณ์

  • ติดตั้งบน Windows ที่ไม่มี PHP, MySQL หรือ XAMPP มาก่อน สร้างบัญชีและเปิดใช้งานได้
  • ทดสอบทั้ง Windows 10/11 x64 และพาธชื่อบัญชี Windows ภาษาไทยหรือมีช่องว่าง
  • ถอดอินเทอร์เน็ต ตรวจหน้าตา กราฟ ฟอนต์ กระบวนการทำงาน และ PDF/Excel
  • ทำวางยาง → ราคา → ชั่ง → อนุมัติ/ยอดหัก → ใบเสร็จครบ ตรวจยอดและข้อจำกัดตามสิทธิ์ผู้ใช้
  • สำรอง กู้คืน ล้างข้อมูล ปิดเปิดใหม่ และรีสตาร์ต Windows แล้วตรวจว่าข้อมูลคงอยู่
  • กดเปิดซ้ำ ทดสอบพอร์ตชน และถอนติดตั้ง ตรวจว่าไม่ปิดโปรแกรมอื่นและไม่ลบข้อมูลเดิม
  • ตรวจชุดแจกว่าไม่มีข้อมูลจริงของสหกรณ์เดิม และกำหนดช่องทางติดต่อผู้พัฒนาก่อนแจก

10. ข้อมูลส่วนประกอบและผู้ดูแล

โปรแกรมรวม PHP, MariaDB, Dompdf และไลบรารีหน้าเว็บตามต้นแบบ รายละเอียดแหล่งที่มาและใบอนุญาตอยู่ในโฟลเดอร์ licenses ของโปรแกรม พร้อมซอร์ส MariaDB รุ่นที่รวมในชุดติดตั้ง
