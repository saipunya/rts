## วิธีติดตั้ง

ส่วนกำหนดราคายางใช้ `price_form.php`, `price_save.php`, `prices.php` และ `assets/css/prices.css` เพิ่มจากรายการด้านบน โดย `header.php` เพิ่มเมนู “จัดการระบบ → กำหนดราคายาง” เฉพาะ admin ทั้งมือถือและจอใหญ่ หน้าฟอร์มแสดงราคาล่าสุด ปี พ.ศ. อัตโนมัติ และช่วงวางยางย้อนหลัง 2 วันก่อนวันชั่ง ใช้ตัวบันทึกราคาเดิมและไม่เปลี่ยนราคาของรายการที่ชั่งแล้ว

1. อัปโหลดไฟล์ในแพ็กทั้ง 41 ไฟล์ทับตำแหน่งเดิมภายใต้ `/test/` โดยรักษาโครงสร้าง `assets/` และ `partials/` ไว้
2. ทดสอบเปิดหน้าแรกโดยไม่เข้าสู่ระบบ ค้นหาชื่อหรือเลขสมาชิก กรองสถานะ และรอการอัปเดตอัตโนมัติ
3. เมื่อทดสอบผ่าน ใช้ชุดไฟล์เดียวกันอัปโหลดที่เว็บหลัก `/` ได้

แพ็กไม่มี `db_config.php` ไม่มีข้อมูลทดสอบ และไม่มีไฟล์ฐานข้อมูล ให้ใช้ค่าการเชื่อมต่อฐานข้อมูลเดิมของแต่ละตำแหน่ง การเพิ่มเหตุผลใช้ช่อง JSON ประวัติที่มีอยู่แล้ว ไม่ต้องนำเข้า SQL ใหม่สำหรับการเปลี่ยนแปลงชุดนี้

QR ที่ติดใช้งานจริงควรชี้ URL หน้าแรกของเว็บหลัก ไม่ใช่ URL `/test/`

## พฤติกรรมของหน้าแรก

- ก่อนส่วน “ข้อมูลจริง เพื่อการทำงานที่เป็นระบบ” มีปริมาณยางแยกแต่ละลานของรอบล่าสุด แสดงน้ำหนักที่ยืนยันชั่งแล้ว จำนวนรายการ และยอดรวมทุกลาน อัปเดตทุก 10 วินาที ไม่เปลี่ยนตามคำค้นหรือตัวกรอง และไม่รวมรายการยกเลิกหรือคนละรอบ
- หน้าแรกแสดงสูงสุด 20 รายการ มีลิงก์ดูรายการทั้งหมดที่รักษาคำค้นและสถานะไว้ หน้ารายการทั้งหมดแบ่งหน้าละ 20 รายการ มีปุ่มก่อนหน้า/ถัดไป และเปิดได้โดยไม่เข้าสู่ระบบ
- ช่องค้นหาอยู่เหนือรายการและตัวกรองสถานะ ภายในกรอบกระดานเดียวกัน ส่วนต้นหน้ามีปุ่มกระโดดไปยังกระดาน
- พิมพ์แล้วค้นหาอัตโนมัติหลังหยุดพิมพ์ 350 มิลลิวินาที รองรับการประกอบอักษรภาษาไทย ยกเลิกคำขอเก่า และไม่เลื่อนหน้าจอระหว่างพิมพ์
- อ่านข้อมูลสาธารณะได้โดยไม่เข้าสู่ระบบ ค้นหาชื่อหรือนามสกุลบางส่วนได้ ส่วนเลขสมาชิกค้นหาแบบตรงกันและรักษาเลขศูนย์นำหน้า
- ภาพรวมมี 4 บล็อก: วางยาง ชั่งแล้ว น้ำหนักรวม และผู้ส่งยางในรอบ โดยรวมสมาชิกกับเกษตรกรทั่วไปไว้บล็อกเดียวและแยกตัวเลขสองบรรทัด ไม่แสดงบล็อกออกใบเสร็จแล้ว
- จำนวนสมาชิกและเกษตรกรทั่วไปนับแบบคนไม่ซ้ำในรอบ รวมผู้ที่รอชั่ง ไม่รวมรายการยกเลิก ตัวเลขไม่เปลี่ยนตามคำค้นหรือตัวกรอง ใช้เลขสมาชิก/รหัสบุคคลเป็นหลัก และใช้ชื่อเป็นข้อมูลสำรองเมื่อไม่มีรหัส
- ภาพรวมและกระดานอ้างอิงรอบราคาล่าสุด แสดงชัดว่าเป็นรอบวันนี้ รอบก่อนหน้า หรือประกาศล่วงหน้า
- เรียกเฉพาะช่วงวางยาง 2 วันก่อนวันราคาตามกติกาเดิม และรายการที่ชั่งในรอบนั้น
- แสดงไม่เกิน 20 รายการล่าสุดตามตัวกรอง การค้นหาชื่อหรือเลขสมาชิกค้นจากทุกรายการในรอบก่อนจำกัดจำนวน
- “ชั่งแล้ว” เป็นหมุดหมายรวมถึงรายการที่ออกใบเสร็จแล้วด้วย ส่วนป้ายแต่ละแถวแสดงขั้นตอนล่าสุด
- ไอคอนหน้าชื่อใช้วงกลมเครื่องหมายลบสีส้มสำหรับมียอดหัก เครื่องหมายถูกสีเขียวสำหรับยืนยันไม่มียอดหัก และนาฬิกาสีเทาสำหรับรายการที่ยังไม่ยืนยันยอดหัก ไม่มีข้อความกำกับบนหน้าจอ
- รายการยกเลิกไม่แสดงและไม่รวมสถิติ
- แสดงชื่อ–นามสกุลเต็มพร้อมหมายเหตุเป็นข้อมูลหลัก เลขสมาชิก ลาน และจำนวนกระสอบเป็นข้อมูลรอง ไม่ส่งยอดหักหรือยอดเงินรายบุคคลออกทาง API
- จำคำค้นบนเบราว์เซอร์ของอุปกรณ์นั้น มีปุ่มล้าง และแยกค่าที่จำไว้ระหว่าง `/test/` กับ `/`
- อัปเดตทุก 10 วินาทีขณะเปิดดูหน้า หยุดเรียกซ้ำเมื่อซ่อนแท็บ และอัปเดตทันทีเมื่อกลับมา
- เครือข่ายขัดข้องแสดงเวลาข้อมูลล่าสุด ไม่ลบรายการเดิม และลองเชื่อมต่อใหม่
- “ออกใบเสร็จแล้ว” หมายถึงระบบมีบันทึกการออกใบเสร็จ ไม่ใช่การยืนยันพิมพ์กระดาษ ส่งมอบ หรือจ่ายเงิน
- หน้าแรกอ่านข้อมูล ไม่มีการเปลี่ยนขั้นตอนอนุมัติ ชั่ง หรือออกใบเสร็จ

## การตรวจสอบ

- `php tests/public_dashboard.php`: สถานะ ตัวกรอง การค้นหา การแสดงชื่อและหมายเหตุ การยกเลิก การจำกัดจำนวน และการอ่านโดยไม่แก้ข้อมูล
- `php tests/weighing_integration.php`: กระบวนการทำงานเดิมและประวัติแก้วันที่
- `python3 tests/deployment_paths.py`: path และ session ระหว่าง `/` กับ `/test/`
- Playwright บนฐานข้อมูลทดสอบแยก: 320, 375, 768, 1024 และ 1440px; ค้นหาและล้าง; ตัวกรอง; อัปเดตอัตโนมัติหลังข้อมูลเปลี่ยน; เครือข่ายขัดข้องและเชื่อมต่อกลับ; เปิดแบบไม่เข้าสู่ระบบที่ `/test/`

ไฟล์ `tests/public_dashboard.php`, `tests/weighing_integration.php` และเอกสารนี้ไม่จำเป็นต่อการเปิดเว็บไซต์ จึงไม่รวมในแพ็ก runtime

## การอัปเดตหน้ารายการตามสถานะ

`public_collection_list.php` ตรวจข้อมูลทุก 10 วินาที หน้า 1 อัปเดตโดยไม่โหลดทั้งหน้า ส่วนหน้า 2 เป็นต้นไปคงรายการเดิมและแจ้งให้กดแสดงข้อมูลล่าสุด หากหน้าที่ดูหายไปจะปรับไปหน้าที่มีข้อมูลหลังผู้ใช้กดอัปเดต คงคำค้น สถานะ และตำแหน่งจอไว้ หยุดเรียกข้อมูลเมื่อซ่อนแท็บ และเก็บข้อมูลล่าสุดไว้หากเครือข่ายขัดข้อง

## ใบแจ้งยอดความสูงตามข้อมูล

`print_deduction_check.php` คงความกว้างกระดาษ 80 มม. และคำนวณความสูงจากข้อมูลก่อนพิมพ์ รวมขอบบน–ล่าง ไม่กำหนดความสูง 120 มม. ตายตัว รองรับชื่อและหมายเหตุยาวโดยวัดที่ความกว้างพิมพ์จริง รอฟอนต์พร้อมก่อนพิมพ์ และคงขั้นตอนบันทึกประวัติ/กลับหน้ารออนุมัติเดิม หากไดรเวอร์บังคับกระดาษ A4 ต้องตั้งชนิดกระดาษ 80 มม. แบบม้วนให้ตรงกับเครื่อง เว็บไม่สามารถสั่งตัดกระดาษของเครื่องพิมพ์ผ่านหน้าต่างพิมพ์โดยตรงได้

## สิทธิ์เมนูรายบัญชี

แพ็กรวมเพิ่มระบบกำหนดสิทธิ์เมนูรายบัญชี โดยคงเมนู admin ไว้ตามเดิม รวมไฟล์ runtime ที่ไม่ซ้ำทั้งหมด 41 ไฟล์ ดูรายชื่อ 13 ไฟล์ของส่วนสิทธิ์และวิธีใช้งานใน `docs/user-menu-permissions.md` ระบบสร้างตารางสิทธิ์อัตโนมัติ และคง `db_config.php` ของโฮสต์เดิมไว้

## admin แก้ไขน้ำหนัก

รวมไฟล์แก้ไขน้ำหนักเฉพาะ admin ทุกขั้นตอน ดูรายการและวิธีใช้ใน `docs/admin-weight-edit.md`

## หน้าวางยางอัปเดตอัตโนมัติ

เพิ่ม `wang_main.php` และ `assets/js/wang-main-live.js` ตรวจข้อมูลทุก 5 วินาที อัปเดตจำนวนรายการ กระสอบแต่ละลาน ยอดรวม สถานะงาน และรอบราคาล่าสุดโดยไม่โหลดทั้งหน้า ดึงทันทีเมื่อกลับมาเปิดแท็บ หยุดเมื่อซ่อนแท็บ เก็บข้อมูลเดิมเมื่อเครือข่ายขัดข้อง และยังตรวจสิทธิ์วางยางทุกคำขอ ทดสอบการเพิ่ม/แก้ไขจริงข้าม session ในฐานข้อมูลแยกแล้ว
