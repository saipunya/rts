# รุ่นทดลอง RTS สำหรับ Windows เครื่องเดียว

ขอบเขตที่ตกลงกับเจ้าของระบบ: นำระบบรวบรวมยางไปให้สหกรณ์อื่นทดลอง เพื่อเตรียมจำหน่าย โดยเริ่มจาก Windows เครื่องเดียวก่อน

เอกสารนี้เป็นผลสำรวจและแผนพัฒนา ยังไม่ใช่ชุดติดตั้ง และยังไม่ได้ยืนยันการทำงานบน Windows

## ผลสำรวจโค้ด

- สำรวจจาก branch `new-feature`, commit `d5545bd` โดยยังไม่ได้เทียบกับ GitHub ล่าสุด
- ระบบใช้ PHP และ MySQL/MariaDB ผ่าน mysqli มี Composer lock และ Dompdf สำหรับ PDF
- `app_bootstrap.php` รองรับการติดตั้งในโฟลเดอร์ย่อยและแยก session ตามตำแหน่งติดตั้งแล้ว
- `header.php` และ `footer.php` ยังระบุชื่อสหกรณ์เดิมโดยตรง และ footer มีข้อมูลติดต่อ ต้องปรับเป็นค่าตั้งของแต่ละการติดตั้ง
- `rts_db.sql` มีข้อมูลสมาชิก รายการรับซื้อ ราคา และบัญชีผู้ใช้ จึงไม่ใช้ไฟล์นี้ทั้งไฟล์เป็นข้อมูลแจกทดลอง
- SQL เดิมมีเพียงบางตาราง ส่วนโค้ดมีการสร้างและเพิ่มคอลัมน์ขณะใช้งาน เช่น `weighing_functions.php`, `collection_round_functions.php`, `cancellation_functions.php` ต้องรวบรวม schema ให้ครอบคลุมก่อนทำตัวติดตั้ง
- หลายหน้าอาศัย Bootstrap, Lucide, Chart.js และฟอนต์จาก CDN ต้องเตรียมไฟล์ในเครื่องและตรวจทุกหน้าก่อนระบุว่ารองรับออฟไลน์
- มี `demo_reset.php` และ `demo_reset_functions.php` สำหรับล้างข้อมูลโดยผู้ดูแลและคงบัญชีไว้ แต่ยังต้องทดสอบกับฐานข้อมูลรุ่นแจกทดลอง
- การตรวจครั้งนี้ไม่ได้เชื่อมต่อหรือเปลี่ยนฐานข้อมูลจริง

## รูปแบบรุ่นแรก

ติดตั้งแยกหนึ่งชุดต่อหนึ่งสหกรณ์ เปิดจากไอคอนบน Desktop แล้วใช้งานในเบราว์เซอร์ผ่าน localhost ฐานข้อมูลอยู่ในเครื่องเดียวกัน การแจกครั้งแรกใช้ข้อมูลสมมติเท่านั้น

ยังไม่รวมการใช้หลายเครื่องพร้อมกัน ระบบสมัครสมาชิกออนไลน์ การชำระเงิน และการบังคับวันหมดอายุ ต้องตกลงรูปแบบขายก่อนเพิ่มระบบสิทธิ์ใช้งาน

## งานที่ต้องทำตามลำดับ

1. แยกค่าตั้งสหกรณ์: ชื่อ ที่อยู่ โทรศัพท์ และโลโก้ ให้หน้าเว็บและเอกสารใช้ค่าเดียวกัน โดยคงค่าของการติดตั้งเดิมไว้
2. สร้างฐานข้อมูลติดตั้งใหม่จาก schema ที่ครบทุกโมดูล ไม่บรรจุสมาชิก รายการธุรกรรม รหัสผ่าน หรือค่าการเชื่อมต่อเดิม สร้างผู้ดูแลใหม่ตอนติดตั้ง
3. สร้างข้อมูลสมมติที่สาธิตสมาชิก วางยาง ชั่ง ราคา ยอดหัก อนุมัติ และใบเสร็จได้ ตรวจให้ยอดและลำดับขั้นตอนสัมพันธ์กัน
4. รวมทรัพยากรหน้าเว็บและฟอนต์ไว้ในเครื่อง ตรวจการทำงานเมื่อไม่มีอินเทอร์เน็ต
5. จัดชุด PHP เว็บเซิร์ฟเวอร์และ MariaDB สำหรับ Windows พร้อมตัวเริ่มและหยุดระบบ ผูกบริการกับ loopback สำหรับรุ่นเครื่องเดียว เก็บข้อมูลและค่าตั้งในตำแหน่งที่เขียนได้และคงอยู่เมื่ออัปเดต
6. ทำสำรองและกู้คืนฐานข้อมูล พร้อมตรวจความเข้ากันได้ของรุ่น และสำรองก่อนอัปเดตหรือเปลี่ยน schema
7. บรรจุเป็นตัวติดตั้ง Windows พร้อมไอคอน เปิดเบราว์เซอร์เมื่อระบบพร้อม และคู่มือภาษาไทย ตรวจสิทธิ์แจกจ่ายส่วนประกอบที่รวมไปด้วย

## เกณฑ์ก่อนส่งให้สหกรณ์ทดลอง

- ติดตั้งบน Windows เครื่องทดสอบที่ไม่มี PHP หรือฐานข้อมูลมาก่อน และเปิดระบบได้โดยไม่ต้องตั้งค่าโค้ดเอง
- เข้าสู่ระบบด้วยผู้ดูแลที่สร้างใหม่ เปลี่ยนชื่อสหกรณ์แล้วหน้าเว็บและเอกสารแสดงตรงกัน
- ทำกระบวนการวางยาง ชั่ง บันทึกราคา ยอดหัก อนุมัติ และพิมพ์ใบเสร็จครบ พร้อมตรวจยอดเงิน
- PDF และ Excel แสดงข้อมูลและภาษาไทยถูกต้อง
- ปิดแล้วเปิดระบบใหม่หรือรีสตาร์ต Windows ข้อมูลยังอยู่ ตรวจกรณีพอร์ตถูกใช้อยู่และไม่เปิดเซิร์ฟเวอร์ซ้ำ
- ถอดอินเทอร์เน็ตแล้วใช้งานหน้าหลักและขั้นตอนสาธิตได้ครบ
- สำรองข้อมูลและกู้คืนลงการติดตั้งทดสอบอีกชุด แล้วตรวจจำนวนรายการและยอดสำคัญ
- ล้างข้อมูลสมมติได้ตามตัวเลือก โดยคงบัญชีผู้ดูแลและค่าตั้งสหกรณ์
- ตรวจไฟล์แจกทั้งหมดว่าไม่มีข้อมูลสมาชิก ธุรกรรม บัญชี หรือค่าการเชื่อมต่อของสหกรณ์เดิม
- อัปเดตแล้วข้อมูลเดิมยังอยู่ และถอนการติดตั้งโดยไม่ลบข้อมูลผู้ใช้โดยอัตโนมัติ

## สถานะ

เสร็จแล้ว: สำรวจโค้ดและกำหนดขอบเขตรุ่น Windows เครื่องเดียว

ยังต้องทำ: ปรับโปรแกรม สร้างข้อมูลสมมติ รวม runtime ทำชุดติดตั้ง และทดสอบบน Windows จริงตามรายการด้านบน

## ความคืบหน้า: ชุดติดตั้งรวมส่วนประกอบ

สร้างสำเนาแอปและชุดประกอบตัวติดตั้งไว้ใน `demo/` แล้ว มี runtime Windows, ทรัพยากรหน้าเว็บในเครื่อง, ตัวเปิด/ปิด, สำรอง/กู้คืน และคู่มือภาษาไทย ดูสถานะและข้อจำกัดล่าสุดที่ `demo/README.md` และ `demo/windows/VALIDATION.md` ยังต้องตรวจรับบน Windows จริงก่อนแจกใช้งาน

รุ่นทดลอง 0.2.0 เพิ่มระยะใช้งาน 60 วันและรหัสที่ผู้พัฒนาออกให้แล้ว ผู้ติดต่อคือ สุเมธ ชูรัตน์ โทร 080-8281906 · LINE saipunya เครื่องมือออกรหัสอยู่ที่ `demo/developer-tools/` และไม่รวมในตัวติดตั้ง Windows
