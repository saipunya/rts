# ติดตั้งเว็บทดสอบใน /test/

โค้ดชุดเดียวรองรับทั้งเว็บหลักและโฟลเดอร์ย่อย ลิงก์และฟอร์มใช้พาธสัมพันธ์
ระบบตรวจตำแหน่งจาก SCRIPT_NAME ของ PHP เพื่อแยก session และลิงก์หลังเข้าสู่ระบบอัตโนมัติ
ไม่ต้องตั้งชื่อโดเมนหรือแก้ลิงก์เป็น /test/ ด้วยตนเอง

1. สำรองไฟล์และฐานข้อมูลเว็บจริง
2. อัปโหลดไฟล์ระบบพร้อม vendor และ assets ลง public_html/test/
3. สร้างฐานข้อมูลทดสอบแยก แล้วนำเข้า SQL โครงสร้าง/ข้อมูลตั้งต้น
4. สร้าง db_config.php ใน /test/ จาก db_config.sample.php ให้ชี้ฐานข้อมูลทดสอบ
5. เปิด /test/login.php เข้าสู่ระบบ ทดสอบวางยาง ชั่ง อนุมัติ ยอดหัก และพิมพ์
6. เมื่อต้องการทดสอบ ให้ admin แก้วันที่วางยางที่ manage_wang.php เป็น 1 หรือ 2 วันก่อนวันที่ราคายางล่าสุด โดยวันที่ราคายางต้องไม่อยู่ในอนาคต

ห้ามคัดลอก db_config.php ที่ชี้ฐานข้อมูลจริงไปใช้ใน /test/
ปุ่มล้างข้อมูลเดโมจะทำงานกับฐานข้อมูลที่กำหนดไว้ในไฟล์นี้

เมื่อทดสอบผ่าน ให้อัปโหลดโค้ดชุดเดียวไปเว็บหลักโดยคง db_config.php ของเว็บจริงไว้
หากมีการเพิ่มตาราง/คอลัมน์ ให้สำรองฐานข้อมูลก่อนและตรวจการอัปเกรด schema ตามเวอร์ชัน
ไม่ต้องนำข้อมูลทดสอบไปทับฐานข้อมูลจริง

หลังอัปเดต session แบบแยกตำแหน่ง ผู้ใช้ต้องเข้าสู่ระบบใหม่หนึ่งครั้ง
การเข้า/ออกจากระบบใน /test/ จะไม่เปลี่ยน session ของเว็บหลัก
แอปที่เพิ่มบนหน้าจอมือถือจาก /test/ จะเปิดกลับมาภายใต้ /test/ เช่นกัน

ตรวจการแยก session และพาธได้ด้วย `python3 tests/deployment_paths.py`
การทดสอบนี้ใช้ PHP server ชั่วคราวและไม่เชื่อมต่อฐานข้อมูล
