# แก้ไขน้ำหนักเฉพาะ admin

admin เปิดแก้ไขน้ำหนักได้จากหน้าชั่ง อนุมัติหลังชั่ง บันทึกยอดหัก และใบเสร็จที่ออกแล้ว ต้องกรอกเหตุผลทุกครั้ง บันทึกผู้แก้ เวลา น้ำหนัก และยอดเงินก่อน–หลังในประวัติ

ปรับน้ำหนักในข้อมูลวางยาง ผลชั่ง และรับซื้อพร้อมกันใน transaction เดียว คำนวณยอดเงินตามราคาที่ตรึงตอนชั่ง คงยอดหักและสถานะอนุมัติเดิม ป้องกันฟอร์มเก่าเขียนทับข้อมูลใหม่ ไม่อนุญาตแก้รายการยกเลิก บัญชี user บันทึกการชั่งครั้งแรกได้ตามสิทธิ์ แต่แก้ไขน้ำหนักที่บันทึกแล้วไม่ได้

หากออกใบเสร็จแล้ว เก็บข้อมูลใบเสร็จฉบับแรกไว้ พร้อมผู้แก้ล่าสุด ให้พิมพ์ฉบับใหม่และแจ้งผู้เกี่ยวข้องให้ใช้ข้อมูลล่าสุด การแก้ไขไม่ย้อนสถานะและไม่บันทึกการจ่ายเงินเพิ่มเติมอัตโนมัติ

## ไฟล์อัปโหลดรอบนี้ (8 ไฟล์)

1. `admin_weight_edit.php` — ไฟล์ใหม่
2. `weighing_functions.php`
3. `weigh_wang.php`
4. `approve_weighing.php`
5. `rubbers.php`
6. `printed_receipts.php`
7. `collection_history.php`
8. `permission_functions.php`

อัปโหลดทั้งชุดไป /test/ ก่อน จากนั้นใช้ชุดเดียวกันที่ / ได้ คง db_config.php เดิม ไม่มีการเพิ่มตารางใหม่ในงานรอบนี้ หากยังไม่ได้อัปโหลดระบบสิทธิ์เมนู ต้องอัปโหลดแพ็ก 13 ไฟล์ก่อนด้วย

## ตรวจสอบ

ทดสอบกระบวนการชั่งเดิม การแก้ในขั้นส่งตรวจ ยืนยันยอดหัก และหลังออกใบเสร็จ การคำนวณราคาเดิม การเก็บใบเสร็จฉบับแรก การป้องกันฟอร์มเก่า และการปฏิเสธผู้ใช้ทั่วไปด้วย tests/weighing_integration.php ทดสอบ URL ของหน้าแก้ไขด้วยบัญชี user จริงใน tests/user_permissions_http.py
