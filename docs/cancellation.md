# ยกเลิกรายการทั้งกระบวนการ

## การใช้งาน

เข้าเมนู “ยกเลิกรายการ” (`cancel_collection.php`) ด้วยบัญชี admin เท่านั้น
ค้นหาชื่อ เลขสมาชิก กลุ่ม เลขรายการ วันที่ หรือลาน แล้วเลือก “ตรวจสอบรายการ”
ตรวจข้อมูล ระบุเหตุผล พิมพ์คำว่า “ยกเลิก” และกดยืนยันการยกเลิกทั้งกระบวนการ
รายการที่ยกเลิกแล้วไม่สามารถยกเลิกซ้ำ แก้ไข ลบ หรือดำเนินการต่อได้
ระบบนี้ไม่มีปุ่มคืนสถานะ

สถานะรายการมี “ปกติ” และ “ยกเลิก” แยกจากขั้นตอนการทำงาน
รายการเก่าที่ไม่มีสถานะจะเป็นปกติตามค่าเริ่มต้น
สถานะเดิม cancelled/canceled/deleted ของการวางยางยังถือเป็นยกเลิก และเชื่อมสถานะไปยังรายการรับซื้อเดิม

## ผลต่อข้อมูล

- เก็บการวางยาง ผลชั่ง การอนุมัติ ยอดหัก และใบเสร็จไว้ทั้งหมด
- เก็บภาพข้อมูลก่อนยกเลิก ผู้ยกเลิก บัญชีผู้ใช้ วันเวลา และเหตุผล
- ไม่รวมในสถิติ จำนวนสมาชิก/รายการ กระสอบ น้ำหนัก ยอดเงิน ยอดหัก และสุทธิ
- คิวทำงานปกติ รายการใบเสร็จ และรายงาน/Excel แสดงเฉพาะรายการปกติ
- หน้ายกเลิก หน้าประวัติ และหน้าจัดการวางยางยังเรียกดูรายการยกเลิกได้
  จำนวนรายการในหน้าค้นหาตรวจสอบย้อนหลังเป็นจำนวนผลค้นหา รวมรายการยกเลิก ไม่ใช่สถิติธุรกิจ
- ใบเสร็จที่เคยออกแล้วและใบตรวจสอบจะแสดง “ยกเลิก” เมื่อเปิดเอกสารใหม่
  กระดาษและไฟล์ที่ส่งออกก่อนยกเลิกไม่เปลี่ยนย้อนหลัง

## การติดตั้ง

สำรองฐานข้อมูลก่อนอัปโหลดชุดไฟล์ และอัปโหลดไฟล์ PHP ทุกไฟล์ในชุดนี้พร้อมกัน
ต้องมี cancellation_functions.php และ cancel_collection.php เพิ่มในโฟลเดอร์เดียวกับ functions.php
ไม่ต้องเปลี่ยน db_config.php และไม่ต้องนำเข้าข้อมูลทดสอบ

ระบบเพิ่ม record_status ใน tbl_wangyang และ tbl_rubber โดยมีค่าเริ่มต้น normal
และสร้างตาราง tbl_collection_cancellations อัตโนมัติ
บัญชีฐานข้อมูลต้องมีสิทธิ์ ALTER และ CREATE ตามการอัปเกรด schema เดิมของระบบ
ตารางที่ร่วมธุรกรรมต้องเป็น InnoDB จึงจะยกเลิกได้

การตรวจสอบ: `php tests/weighing_integration.php` ใช้ฐานข้อมูลทดสอบแยกและลบฐานข้อมูลทดสอบเมื่อเสร็จ
